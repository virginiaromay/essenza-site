# Essenza Quiz — Quiz de Estilo de Interiorismo

Quiz interactivo que descubre el perfil de estilo de diseño de interiores del usuario.

## Estilos
- Contemporáneo
- Natural
- Japandi
- Industrial
- Minimalista

## Cómo publicar en Vercel (gratis)

### Paso 1 — Subir a GitHub
1. Crear un repositorio nuevo en github.com (ej: `essenza-quiz`)
2. Subir todos estos archivos al repositorio

### Paso 2 — Conectar con Vercel
1. Ir a [vercel.com](https://vercel.com) → Sign up con GitHub
2. Clic en **"New Project"**
3. Seleccionar el repositorio `essenza-quiz`
4. Vercel detecta Create React App automáticamente
5. Clic en **"Deploy"**
6. En 2 minutos tenés una URL tipo `essenza-quiz.vercel.app`

### Paso 3 — Integrar en tu web
Pegá esto donde quieras mostrar el quiz en tu página:

```html
<iframe 
  src="https://TU-URL.vercel.app" 
  width="100%" 
  height="900px"
  frameborder="0"
  style="border:none;">
</iframe>
```

### Paso 4 — Instagram
1. Ir a [linktree.com](https://linktree.com) → crear cuenta gratis
2. Agregar un botón: "Descubrí tu estilo ✨" → URL del quiz
3. En tu bio de Instagram: "Link en bio 👆"

## Desarrollo local

```bash
npm install
npm start
```
